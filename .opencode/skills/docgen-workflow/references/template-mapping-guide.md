# Template Mapping Guide

Maps content sections from `content.ir.json` to template sections in `template.docx`.
Run this BEFORE any clone/insert operations. Produces a mapping table that
determines insertion points, cleanup targets, and preserved sections.

---

## Step 1: Classify Template Sections

Read the template outline via `officecli view <template> outline` and classify each section:

### PRESERVE — Keep as-is, never modify

| Section | Reason |
|---------|--------|
| Cover page / Title page | Front matter, no content maps to it |
| TABLE OF CONTENTS | Auto-generated by Word, must not be modified |
| LIST OF ABBREVIATIONS | Template-specific metadata |
| LIST OF TABLES/CHARTS | Template-specific metadata |
| ABSTRACT | Template-specific (may have abstract) |
| REFERENCES | Template's own references section (if content has its own, see below) |
| APPENDIX | Template appendix |
| SUPERVISOR'S COMMENTS | Template-specific |

### REPLACE — Insert content here, may replace placeholder text

| Section | Typical Replacement Strategy |
|---------|----------------------------|
| CHAPTER 1. INTRODUCTION | Content's introduction / opening chapter |
| CHAPTER 2. LITERATURE REVIEW | Content's theory / literature review (most common target) |
| CHAPTER 3. METHODOLOGY | Content's methodology section |
| CHAPTER 4. FINDINGS AND DISCUSSION | Content's findings / discussion |
| CHAPTER 5. CONCLUSIONS AND RECOMMENDATIONS | Content's conclusions |

### REMOVE — Delete entirely, no content maps to it

| Element | Why Remove |
|---------|------------|
| Empty placeholder paragraphs | Leftover from template, no purpose |
| Duplicate headings | Template's placeholder heading conflicts with new content heading |
| Section placeholder text (e.g., "Click here to enter text") | Template filler, not real content |

---

## Step 2: Map Content to Template

For each content section in `content.ir.json`, determine:

1. **Target template section**: Which PRESERVE/REPLACE section does this belong to?
2. **Insertion point**: The `@paraId` of the LAST paragraph of the template element BEFORE the insertion target
3. **Cleanup needed**: Any template paragraphs to remove

### Mapping Rules

**Rule 1: Content chapter → Template section by name**
- If content has "CƠ SỞ LÝ THUYẾT" → maps to "CHAPTER 2. LITERATURE REVIEW"
- If content has "PHƯƠNG PHÁP NGHIÊN CỨU" → maps to "CHAPTER 3. METHODOLOGY"
- If content has "KẾT QUẢ VÀ THẢO LUẬN" → maps to "CHAPTER 4. FINDINGS AND DISCUSSION"
- If content has "KẾT LUẬN" → maps to "CHAPTER 5. CONCLUSIONS AND RECOMMENDATIONS"
- Otherwise → append after the last REPLACE section (but BEFORE APPENDIX/SUPERVISOR'S COMMENTS)

**Rule 2: References section** — If content has its own TÀI LIỆU THAM KHẢO or REFERENCES section, it can either:
- Replace the template's REFERENCES section, OR
- Be inserted after the last content chapter (before template REFERENCES)

Choose based on whether the template's REFERENCES has actual content or is a placeholder.

**Rule 3: Never append at document end** — Insertion point MUST be before APPENDIX or SUPERVISOR'S COMMENTS. Content should never appear after these sections.

---

## Step 3: Determine Anchor

The anchor is the `@paraId` of the last preserved element BEFORE the insertion target.

**Formula**: `anchor = @paraId of the paragraph just before where you want to insert`

Examples:
- Inserting after CHAPTER 1 heading (removing it first) → anchor = paragraph before CHAPTER 1
- Inserting into CHAPTER 2 section → anchor = last paragraph of CHAPTER 1 (after removing CHAPTER 2 placeholder)
- Inserting at end of content sections → anchor = last paragraph of the last content section

**CRITICAL**: The initial anchor must be queried from the document, not hardcoded:
```bash
officecli query <file> "/body/p[@paraId=<last_preserved_before_insertion>]" --json
```

---

## Step 4: Cleanup Plan

List template elements to remove:

```bash
# Remove placeholder headings that duplicate content
officecli remove <file> /body/p[@paraId=<placeholder_h1>]
officecli remove <file> /body/p[@paraId=<placeholder_h2>]

# Remove empty placeholder paragraphs in target sections
officecli remove <file> /body/p[@paraId=<empty_para>]
```

Only remove elements that:
1. Have no content mapping to them
2. Would create duplicates with new content
3. Are in the REPLACE sections only — never remove PRESERVE elements

## Example Mapping Table

```
CONTENT (content.ir.json)         → TEMPLATE SECTION    → ACTION    → ANCHOR
────────────────────────────────────────────────────────────────────────────
h1_1: "CƠ SỞ LÝ THUYẾT"           → CHAPTER 2 heading    → REPLACE   → lastParaId of CHAPTER 1
h2_1_1: "Tầm quan trọng..."        → after h1_1           → INSERT    → h1_1's paraId
h2_1_2: "Các thách thức..."        → after h2_1_1 body    → INSERT    → last body paraId of h2_1_1
...
h1_3: "TÀI LIỆU THAM KHẢO"        → after last content    → INSERT    → last body paraId of h2_2_2
                                    → before APPENDIX

PRESERVE: ACKNOWLEDGEMENTS         → keep as-is           → PRESERVE  → (no action)
PRESERVE: TABLE OF CONTENTS        → keep as-is           → PRESERVE  → (no action)
PRESERVE: REFERENCES (template)    → remove if content has own references  → REMOVE
PRESERVE: SUPERVISOR'S COMMENTS    → keep as-is           → PRESERVE  → (no action)

REMOVE: CHAPTER 2 placeholder text → /body/p[@paraId=X]   → REMOVE    → officecli remove
```
